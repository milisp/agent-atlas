# Agent Atlas agent guide

Agent Atlas is an independent macOS app derived from Syrtis. Read `README.md` for current product scope, `CONTRIBUTING.md` for local build guidance, and `docs/knowledge/README.md` for inherited architecture and verification references. The knowledge base is upstream-oriented; do not present inherited Syrtis facts as Agent Atlas product promises.

## Project rules

- Write documentation and code comments in English unless the file is localized.
- Preserve inherited copyright and license notices.
- Keep user data local in the workspace report path. Do not upload prompts, code, or workspace names.
- Keep private product and pricing notes out of tracked changes.
- Do not commit, push, publish, or create a release unless the user explicitly asks.
- Preserve unrelated user changes and work in an isolated worktree when the source checkout is dirty.
